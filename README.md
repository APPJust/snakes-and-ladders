# 蛇梯棋：大學四年（雙人連線對戰）

- 作者：資通四勤 121200025 王小明（第 25 題示範用的虛構署名）
- 網址：https://appjust.github.io/snakes-and-ladders/
- 原始碼：https://github.com/APPJust/snakes-and-ladders

1 到 100 格是大學四年：停在梯子底部＝考到證照，往上爬；停在蛇頭＝被當，滑下去。兩台瀏覽器用 WebRTC 直接連線對戰，也可以在同一台電腦兩個人輪流練習。

## 規則

1. 10×10 共 100 格，雙方從格子外的起點出發，輪流擲一顆骰子，往前走點數那麼多格。
2. 停在梯子底部就爬到梯子頂端，停在蛇頭就滑到蛇尾；棋盤上固定有 6 座梯子、6 條蛇（位置寫在 `game.js`）。
3. 擲出 6 點可以再擲一次（剛好用 6 點走到 100 就直接獲勝）。
4. 要剛好走到第 100 格才獲勝；點數超過時要倒退回來，例如在 98 擲出 5，走到 100 再退回 97。倒退後停在蛇頭一樣會滑下去。

| 梯子（考到證照） | 蛇（被當） |
|---|---|
| 4 → 25 考到 TQC 證照 | 27 → 5 微積分被當 |
| 13 → 46 多益 600 分 | 43 → 18 程式設計被當 |
| 33 → 49 考到丙級證照 | 56 → 37 資料結構被當 |
| 42 → 63 專題競賽得獎 | 68 → 47 英文被當 |
| 50 → 69 考到乙級證照 | 87 → 54 演算法被當 |
| 74 → 92 考到雲端證照 | 99 → 78 畢業專題被當 |

## 架構

| 檔案 | 負責 |
|---|---|
| `index.html` | 首頁（暱稱、開房、同一台練習、加入）、等待對手、遊戲畫面、離線提示 |
| `game.js` | 規則的純函式：`newGame`、`checkRoll`、`applyRoll`、`setReady`。不碰畫面，也不自己擲骰子，點數由呼叫的人傳進來 |
| `net.js` | PeerJS 1.5.5：開房、加入、收發 JSON、每 2 秒心跳、6 秒沒心跳就判定離線 |
| `ui.js` | 畫棋盤（SVG）、骰子與棋子動畫、三種模式的流程 |
| `style.css` | 樣式；寬 760px 以下改成上下排列 |

**開房方當裁判，骰子也只有裁判擲。** 加入方按「擲骰」時只送出 `move` 請求，骰子先開始轉；開房方用 `game.js` 檢查是不是輪到加入方，是的話由開房方擲骰子、套用規則，再用 `state` 把完整狀態（含點數 `last.die`）廣播給雙方，加入方的骰子停在這個點數。不是加入方的回合時，開房方回 `reject` 和中文原因。

PeerJS 的 ID 是 `jit1151-25-房間代碼`。PeerJS 伺服器只負責配對；連上對手後和伺服器斷線不影響對戰。

## 訊息格式

| type | 誰送給誰 | 欄位 | 例子 |
|---|---|---|---|
| `hello` | 雙方互送 | `name` 暱稱 | `{"type":"hello","name":"小華"}` |
| `move` | 加入方 → 開房方 | `action` 固定是 `roll` | `{"type":"move","action":"roll"}` |
| `state` | 開房方 → 加入方 | `state` 完整遊戲狀態 | `{"type":"state","state":{"pos":{"host":11,"guest":6},"turn":"guest","last":{"who":"guest","die":6,"from":0,"to":6,"extra":true},…}}` |
| `reject` | 開房方 → 加入方 | `reason` 中文原因 | `{"type":"reject","reason":"還沒輪到你，請等對手擲骰"}` |
| `restart` | 加入方 → 開房方 | 無 | `{"type":"restart"}` |
| `ping` / `pong` | 雙方，每 2 秒 | `t` 時間戳 | `{"type":"ping","t":1795696271466}` |
| `bye` | 關掉分頁的一方 | 無 | `{"type":"bye"}` |

連線時只傳暱稱和遊戲資料，不傳學號、姓名。主控台會印出每一則送出和收到的訊息（心跳不印）。
